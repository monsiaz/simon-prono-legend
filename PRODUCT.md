# Simon Prono Legend

register: brand

## Purpose

Site de pronostics Coupe du Monde 2026 fait pour faire rire les potes de Simon. Un vrai modèle statistique sérieux (Elo + Poisson bivarié + Monte Carlo, backtesté) habillé d'une mise en scène : Simon est « le boss du game », les scores exacts et le vainqueur prédit sont floutés pour tout le monde sauf lui. La tension sérieux-absurde EST le produit.

## Users

Les potes de Simon (FR, mobiles surtout), venus rigoler et suivre le Mondial. Deuxième lecture : visiteurs qui découvrent un modèle statistique honnête et documenté.

## Tone

Premier degré statistique, deuxième degré permanent. Vocabulaire foot de comptoir assumé mélangé à du vocabulaire de papier de recherche. L'humour vient du contraste et de l'autorité absurde du « boss » (« Seul le boss du game peut voir le score. Bye bye. »). Jamais de lourdeur : une vanne par surface suffit.

## Anti-references

Pas un site de bookmaker (aucune cote décimale, aucun parrainage), pas un dashboard SaaS générique, pas un template sports news. Pas de bleu corporate.

## Strategic principles

- La modélisation est publique, le pronostic final est privé : tout ce qui révèle le pick du boss se floute.
- Chaque chiffre affiché sort du modèle ou des données ouvertes. Zéro chiffre inventé.
- Mobile d'abord : ça se partage dans un groupe WhatsApp.
